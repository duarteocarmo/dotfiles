# Pi and tmux status

- `index.ts` sets the current tmux pane status when Pi starts or finishes work.
- `~/.tmux.conf` shows the Pi name and status in tmux.
- `~/Library/Application Support/SwiftBar/Plugins/pi-status.2s.sh` shows every Pi status in the macOS menu bar.
- `~/.local/bin/pi-tmux-jump` focuses Ghostty and selects the chosen tmux pane.
